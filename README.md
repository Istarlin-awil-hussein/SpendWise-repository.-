
# SpendWise - Budget Tracker

## Project Description
SpendWise is a simple budget tracking application that helps users manage their monthly budget, calculate expenses, and know their remaining balance.

## JavaScript Concepts Implemented

This project uses basic JavaScript concepts, including:
- Variables
- Data types
- User input
- Calculations
- Functions
- Console output

## How Variables Are Used
Variables store important budgeting information.

- budget stores the monthly budget.
- expenses stores the total expenses.
- balance stores the remaining money.

## How User Input Is Collected
The application uses the JavaScript prompt() function to ask users to enter their monthly budget and total expenses.

## How Calculations Are Performed
The application subtracts total expenses from the monthly budget to calculate the remaining balance.

Formula:

Remaining Balance = Budget - Expenses

## How Functions Organize the Code
The calculateBalance() function performs the budget calculation.

Functions make the code reusable, organized, and easier to understand.
